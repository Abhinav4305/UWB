signalflow_error_t read_signal(const uint8_t *data_buffer, size_t data_buffer_size, uint32_t signal_semantic, uint32_t array_semantic, signal_info_t *signal)#

Read signal from data buffer.

Parameters:

  • data_buffer – The data buffer to read from.

  • data_buffer_size – The size of the data buffer in bytes.

  • signal_semantic – The semantic ID of the signal.

  • array_semantic – The semantic ID of the array.

  • signal – The signal to write to.

Returns:

SFERR_SUCCESS on success, otherwise an error code.
