# RadarDirect


## Installation of pyx7configuration
We recommend to install the package in a virtual environment. To create a virtual environment, run the following command :
```bash
python -m venv .env
```

To activate the virtual environment, run the following command:
- On Windows:
```
.env\Scripts\activate
```
- On Unix or MacOS:
```bash
source .env/bin/activate
```

Install the pyx7configuration package from file using the following command:
```bash
(.env)>python -m pip install /PATH/TO/pyx7configuration.whl
```
